# Klick nicht den Button! 🚫

Eine freche interaktive Web-App, die dein Durchhaltevermögen testet. Kannst du dem Button widerstehen?

## 🎮 Wie man spielt

1. Öffne die App
2. Versuche, **nicht** auf den Button "Klick mich" zu drücken
3. Ein Timer läuft und zeigt dir, wie lange du dem Drang widerstehst
4. Wenn du drückst: Ein freches Pop-up erscheint und das Spiel ist vorbei

**Ziel:** Wie lange kannst du durchhalten? 😄
